## ⚡ Features
- ⚡ **True Serverless**: Runs completely on Cloudflare Workers with zero VPS required.
- 🪝 **Instant Webhook Execution**: Near-zero cold start times powered by Cloudflare V8 isolates.
- 📦 **Automated Setup Script**: Includes `set-webhook.sh` for one-command deployment.
